pub fn build_audio_channel_filter(op: &Operation) -> Result<Vec<String>, String> {
    let mode = op.params["mode"].as_str().unwrap_or("swap");
    let filter = match mode {
        "swap" => "channelmap=map=FL-FR|FR-FL".to_string(),
        "mono" => "pan=mono|c0=0.5*FL+0.5*FR".to_string(),
        "stereo" => "channelmap=map=FL-FC|FR-FC".to_string(),
        _ => return Err(format!("Unknown channel mode: {}", mode)),
    };
    Ok(vec!["-af".to_string(), filter])
}

  <files>src-tauri/src/ffmpeg/filters.rs</files>
  <action>
Fix the build_audio_channel_filter function (lines 219-230) to produce FFmpeg filter expressions that work with mono, stereo, and multi-channel input sources. The root cause: channelmap filter assumes the named input channels (FL, FR, FC) exist in the input stream, which is not true for mono sources.

Changes to each mode:

1. **"swap" mode** — Prepend `aformat=channel_layouts=stereo` to the chain so mono input is upmixed to stereo before the channel swap. Chain: `aformat=channel_layouts=stereo,channelmap=map=FL-FR|FR-FL`. The `aformat` filter handles channel upmixing/downmixing and auto-inserts channels as needed.

2. **"mono" mode** — Replace `pan=mono|c0=0.5*FL+0.5*FR` with `aformat=channel_layouts=mono`. Reason: `aformat` works with any input channel count, while `pan` with FL/FR references fails on mono input. The `aformat` approach is simpler and FFmpeg handles the mixdown automatically.

3. **"stereo" mode** — The current expression `channelmap=map=FL-FC|FR-FC` discards FL/FR to a center channel that doesn't exist in typical stereo. Rename this mode's filter to do: expand to stereo (if mono) then keep the existing channels: `aformat=channel_layouts=stereo,channelmap=map=FL-FC|FR-FC:channel_layout=2.1`. Wait — this mode name "stereo" but maps to a center channel. Looking at the original intent: this is a "center-mix" operation that collapses stereo to center. Keep the mode name as-is but make it work: use `aformat=channel_layouts=stereo,channelmap=map=FL-FC|FR-FC:channel_layout=2.1` which first ensures stereo input, then remaps to a 2.1 layout (front left, front right, front center). The channelmap `channel_layout=2.1` tells FFmpeg the output layout includes FC.

For all three modes, the key change is the `aformat` prefix which acts as a normalizer — it ensures the input channels match what the downstream filter expects, regardless of the original source's channel count.

After the change, the filter expressions become:
- swap: `aformat=channel_layouts=stereo,channelmap=map=FL-FR|FR-FL`
- mono: `aformat=channel_layouts=mono`
- stereo: `aformat=channel_layouts=stereo,channelmap=map=FL-FC|FR-FC:channel_layout=2.1`
