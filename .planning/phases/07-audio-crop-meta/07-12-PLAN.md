<objective>
Replace CPU-based video filter implementations with GPU-accelerated equivalents where FFmpeg GPU filters exist. Only the Crop operation has GPU filter equivalents (`crop_cuda` + `scale_cuda` for NVENC). The other three operations (FrameDrop: `select`, VideoSpeed: `setpts`, TrimEdges: `trim`) have no GPU filter equivalents in FFmpeg — they remain CPU but still benefit from GPU encoding acceleration which is already in place.

Purpose: User requirement — "全部可 GPU 化的操作 — video filters use GPU, audio stays CPU". GPU filter acceleration for Crop reduces CPU→GPU transfer overhead and improves throughput.

Output: Crop uses NVENC GPU filters; non-GPU-equivalent operations stay CPU; GPU-detection capability flag added to GpuEncoder model.
</objective>

**GPU filter logic** (insert after param clamping, before filter formatting):

When `gpu_encoder` is Some and `supports_gpu_filters()` returns true (currently only NVENC):
- Replace `crop=...` with `crop_cuda=...` (same parameter syntax: w:h:x:y)
- Replace `scale=W:H:flags=lanczos` with `scale_cuda=W:H` (note: `scale_cuda` does not support `flags=lanczos` — omit the flags)
- Wrap the chain with `hwupload_cuda` prefix and `hwdownload,format=nv12` suffix to manage GPU memory transfers
- The `hwupload_cuda` uploads frames to GPU, GPU filters process, `hwdownload,format=nv12` brings back to CPU for any subsequent CPU filters

The GPU expression preserves the same `2*floor(...)` pattern for even offsets (YUV 4:2:0 requirement applies to GPU too) and the same explicit dimensions for scale-back (D-06).

```rust
// After clamping params and determining scale_expr...
let (crop_name, scale_name, gpu_wrap) = if let Some(enc) = gpu_encoder {
    if enc.supports_gpu_filters() {
        // NVENC: use CUDA-accelerated filters
        (
            "crop_cuda",
            "scale_cuda",
            ("hwupload_cuda", "hwdownload,format=nv12"),
        )
    } else {
        ("crop", "scale", ("", ""))
    }
} else {
    ("crop", "scale", ("", ""))
};

// Build scale expression for GPU (scale_cuda doesn't support flags=lanczos)
let scale_expr_gpu = if gpu_wrap.0.is_empty() {
    // CPU: use the existing scale expression with flags
    scale_expr  // already defined above
} else {
    // GPU: simpler scale expression, no flags=lanczos
    if has_orig_dims {
        let orig_w = op.params["origW"].as_u64().unwrap_or(544);
        let orig_h = op.params["origH"].as_u64().unwrap_or(960);
        format!("{}=~{}:{}", scale_name, orig_w, orig_h)
    } else {
        let inv_w = 1.0 / (1.0 - left_pct / 100.0 - right_pct / 100.0);
        let inv_h = 1.0 / (1.0 - top_pct / 100.0 - bottom_pct / 100.0);
        format!("{}=iw*{:.6}:ih*{:.6}", scale_name, inv_w, inv_h)
    }
};

let filter = if gpu_wrap.0.is_empty() {
    // CPU path (unchanged)
    format!(
        "{crop}=iw*(1-{lp}/100-{rp}/100):ih*(1-{tp}/100-{bp}/100):2*floor(iw*{lp}/200):2*floor(ih*{tp}/200),{scale}",
        crop = crop_name, lp = left_pct, rp = right_pct, tp = top_pct, bp = bottom_pct, scale = scale_expr
    )
} else {
    // GPU path: hwupload, GPU filters, hwdownload
    format!(
        "{upload},{crop}=iw*(1-{lp}/100-{rp}/100):ih*(1-{tp}/100-{bp}/100):2*floor(iw*{lp}/200):2*floor(ih*{tp}/200),{scale},{download}",
        upload = gpu_wrap.0, crop = crop_name, lp = left_pct, rp = right_pct,
        tp = top_pct, bp = bottom_pct, scale = scale_expr_gpu, download = gpu_wrap.1
    )
};
```
