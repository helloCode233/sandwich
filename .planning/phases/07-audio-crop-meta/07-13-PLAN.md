<objective>
Enable full GPU acceleration pipeline by adding hardware decoding (NVDec) support. Prior plans added GPU encoding (NVENC) and GPU filters (crop_cuda/scale_cuda), but frames were still decoded on CPU — incurring a CPU→GPU upload penalty for every frame. This plan closes that gap by enabling CUDA hardware decode when NVENC is active, achieving a true GPU end-to-end pipeline: NVDec decode → GPU filters → NVENC encode.

Purpose: Close GPU acceleration gap — hardware decode was the missing piece. Without it, every frame was decoded on CPU and re-uploaded to GPU memory for encoding, defeating much of the acceleration benefit.

Output: Full GPU pipeline (decode + filter + encode) for NVENC-capable systems. Non-GPU filters still receive frames via hwdownload; GPU crop filters run entirely on GPU without CPU round-trips.
</objective>

The crop/scale operations run directly on GPU and stay there for NVENC encoding.
    5. **filters.rs**: `build_filter_args_separated` accepts and forwards the `hwaccel_active` flag to `build_crop_filter`.
    6. Update test call sites for new parameter.
