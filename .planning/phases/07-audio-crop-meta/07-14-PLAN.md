# Phase 07 Plan 14: GPU CUDA Filter Equivalents

## Objective

Convert CPU video filters to NVIDIA GPU (CUDA) equivalents across the codebase.
When NVENC is active with hardware decode (`hwaccel_active`), filters produce
CUDA-native filter chains that run entirely on GPU, avoiding CPU↔GPU round-trips.

## Context

Phase 07 Plan 13 added NVDec hardware decode acceleration. When hwaccel is active,
frames stay in GPU memory end-to-end (NVDec → GPU filters → NVENC). However, only
the `crop_cuda`/`scale_cuda` filters were GPU-native — all other filter builders
used CPU-only filters, requiring `hwdownload` to move frames back to CPU memory.

This plan converts 11 filter builders to GPU-native equivalents when NVENC+hwaccel
is active, keeping filter chains in GPU memory with zero-copy through the pipeline.

## Tasks

### Task 1: GPU FrameDrop — replace select with fps_cuda
- Add `gpu_encoder: Option<&GpuEncoder>`, `hwaccel_active: bool` params to `build_frame_drop_filter`
- GPU: `fps_cuda=fps={target_fps},setpts=N/FRAME_RATE/TB` where target_fps = 30*(interval-1)/interval
- Update dispatch in both `build_filter_args` and `build_filter_args_separated`

### Task 2: GPU VideoSpeed — replace setpts with fps_cuda
- Add GPU params to `build_video_speed_filter`
- GPU video: `fps_cuda=fps=30/{speed:.4f},setpts=N/FRAME_RATE/TB`
- Audio stays CPU atempo (no GPU audio filter)

### Task 3: GPU Flip — hflip_cuda, transpose_cuda
- horizontal → `hflip_cuda` (direct GPU equivalent)
- vertical → `transpose_cuda=clock,transpose_cuda=clock,hflip_cuda`
- both → `transpose_cuda=clock,transpose_cuda=clock` (180° rotation)

### Task 4: GPU Hue, Saturation, Brightness/Contrast — hue_cuda + eq_cuda
- `hue=h=ANGLE:s=SAT` → `hue_cuda=h=ANGLE:s=SAT` (direct)
- `eq=saturation=S:contrast=C:brightness=B` → `eq_cuda=saturation=S:contrast=C:brightness=B` (direct)
- `eq=brightness=B:contrast=C:gamma=G` → `eq_cuda=brightness=B:contrast=C:gamma=G` (direct)
- `colorbalance=rs=R:gs=G:bs=B` → `eq_cuda=brightness={avg}/2` (approximation)

### Task 5: GPU Blur and Sharpen — gblur_cuda, unsharp_cuda
- `gblur=sigma=S` → `gblur_cuda=sigma=S` (direct)
- `unsharp=luma_msize_x=3:...` → `unsharp_cuda=luma_msize_x=3:...` (direct)

### Task 6: GPU TinyScale — scale_cuda
- `scale=W:H:flags=lanczos` → `scale_cuda=W:H` (no lanczos on GPU)

### Task 7: GPU Overlay operations — add GPU params (no CUDA equivalents)
- solid_color_overlay (colorize), gradient_overlay (geq), watermark_blend (geq) have
  no CUDA equivalents — accept GPU params but keep CPU filters as-is
- Documented as deviation

### Task 8: Update dispatch
- Pass gpu_encoder and hwaccel_active through `build_filter_args` to all modified builders
- Pass gpu_encoder and hwaccel_active through `build_filter_args_separated` to all modified builders
- Update all test and integration test callers

### Task 9: Create plan file and SUMMARY.md

## Filters NOT Converted (kept CPU)

- **MicroRotate**: `rotate=angle*PI/180` — no CUDA equivalent for non-90° angles
- **FilmGrain**: `noise=alls=S:allf=T` — no CUDA equivalent
- **MathOverlay**: `geq` expressions — no CUDA equivalent for geq
- All audio filters (aresample, volume, pitch, EQ, channel) — no GPU audio in FFmpeg
- Metadata operations — not video filters
