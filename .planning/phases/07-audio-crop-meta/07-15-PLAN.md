# Phase 07 Plan 15: GPU-Preferred Seed Generation

## Objective

When an NVENC GPU is detected, seed generation should strongly prefer GPU-capable operations to build pure GPU operation chains. CPU-only operations should still be pickable but at much lower probability.

## Context

- `src-tauri/src/commands/seed.rs` — `pick_operation_type` (CPU-default), `generate_seed` command
- `src-tauri/src/models/gpu.rs` — `GpuEncoder` enum
- `src-tauri/src/state.rs` — `AppState.gpu_encoder: Option<GpuEncoder>`

## Tasks

### Task 1: Add GPU-capable detection helper and reweighted pick function
**Type:** auto

Add `is_gpu_capable` helper and `pick_operation_type_gpu_preferred` with GPU-biased weights (700/1000 GPU, 300/1000 CPU).

### Task 2: Wire GPU detection into generate_seed
**Type:** auto

Check `state.gpu_encoder.is_some()` and dispatch to GPU-preferred or CPU-default pick function.

### Task 3: Update test expectations
**Type:** auto

Add coverage test for GPU-preferred variant. Verify existing pre-injection tests pass.
