# Phase 07 Plan 17: GPU-Native Creative Filter Chains

Replace CPU-only video filters with GPU-native CUDA filter chains when NVENC+hwaccel is active.

## Objective

Use creative combinations of real CUDA filters (scale_cuda, pad_cuda, bilateral_cuda, transpose_cuda, colorspace_cuda, yadif_cuda) to achieve similar visual effects to CPU filters. All GPU paths fall back to original CPU code when GPU not available.

## Tasks

1. **GPU Crop** — scale_cuda+pad_cuda chain replaces crop+scale_cuda
2. **GPU Color Operations** — colorspace_cuda round-trip for HueRotate, SaturationAdjust, BrightnessContrast, ColorBalance
3. **GPU GaussianBlur** — bilateral_cuda with sigmaS clamping
4. **GPU FilmGrain** — yadif_cuda on progressive content
5. **Update dispatch** in build_filter_args and build_filter_args_separated
6. **Update is_gpu_capable** and GPU-preferred weights to ~75%
7. **Update tests** for new function signatures

## GPU Filter Mapping

| Operation           | CPU Filter          | GPU Filter                                     |
|---------------------|---------------------|------------------------------------------------|
| Crop                | crop + scale        | scale_cuda + pad_cuda                          |
| HueRotate           | hue                 | colorspace_cuda bt709↔bt2020nc round-trip      |
| SaturationAdjust    | eq                  | colorspace_cuda bt709↔bt2020nc round-trip      |
| BrightnessContrast  | eq                  | colorspace_cuda bt709↔bt2020nc round-trip      |
| ColorBalance        | colorbalance        | colorspace_cuda bt709↔smpte170m round-trip     |
| FilmGrain           | noise               | yadif_cuda + scale_cuda=iw:ih                  |
| GaussianBlur        | gblur               | bilateral_cuda                                 |
